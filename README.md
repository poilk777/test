# Telegram-бот для регистрации и входа пользователей 🤖

## Описание

Telegram-бот с функциональностью регистрации и аутентификации пользователей. Написан на Python с использованием библиотеки `aiogram`.

## Возможности

✅ Регистрация новых пользователей  
✅ Вход в существующие аккаунты  
✅ Валидация ввода (email, пароль)  
✅ Сохранение данных пользователей  
✅ Грамотное меню и навигация  
✅ Система состояний (FSM)

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/ваш-репозиторий.git
cd telegram-bot
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка токена бота

Скопируйте файл `.env.example` в `.env`:

```bash
cp .env.example .env
```

Откройте файл `.env` и добавьте токен вашего бота:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
```

**Как получить токен:**
1. Откройте @BotFather в Telegram
2. Создайте нового бота командой `/newbot`
3. Получите токен от BotFather

### 4. Запуск бота

```bash
python main.py
```

## Использование

### Главная страница

После команды `/start` или `/start` пользователь увидит:

```
👋 Привет! Я ваш помощник по аккаунтам.

Выберите действие:
[📝 Регистрация] [🔐 Вход]
[❓ Помощь]
```

### Регистрация

**Шаг 1:** Введите имя пользователя  
**Шаг 2:** Укажите Email  
**Шаг 3:** Выберите пароль (минимум 6 символов)

### Вход

**Шаг 1:** Введите Email  
**Шаг 2:** Введите пароль  

## Хранилище данных

В текущей реализации данные хранятся в памяти (словарь `users_db`).  
Для продакшена рекомендуется использовать базу данных:
- SQLite
- PostgreSQL
- MongoDB

## Безопасность

⚠️ **Важно!** 
- Никогда не коммитьте файл `.env` с реальным токеном
- Используйте хеширование паролей в продакшене
- Добавьте защиту от SQL-инъекций при использовании БД
- Реализуйте rate-limiting для предотвращения спама

## Технологии

- **Python 3.8+**
- **aiogram 3.0+** - современный фреймворк для Telegram-ботов
- **python-dotenv** - работа с переменными окружения

## Поддержка

При возникновении проблем:
1. Проверьте правильность токена в файле `.env`
2. Убедитесь, что все зависимости установлены (`pip install -r requirements.txt`)
3. Проверьте логи запуска бота
